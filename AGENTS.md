# Project preferences

- UI copy must be functional: labels, values, validation, status, and necessary instructions only.
- Do not add slogans, motivational text, marketing copy, decorative captions, or repetitive explanations.
- Do not use the user's personal name in sample data, placeholders, or examples. Use fictional runner names.
- Preserve the eight configured categories, combined SNES/emulator boards, RTA in integer milliseconds, and competition ranking (1, 1, 3).
- Maintain both dark and light themes when changing UI.

# Git workflow

- Work locally. Do not commit or push unless the user explicitly asks.
- Keep secrets and local environment files out of commits.

# Local preview

- Do not start a preview or development server unless the user explicitly asks.

# Imported mock records

`mock-runs.json` is the source dataset. It contains `{ "enabled": true, "runs": [...] }` and is generated by `npm run mock:import -- "path/to/yi_all_runs.csv" --resolve`.

Set `enabled` to `false`, or delete the JSON file, to show only local submissions. Builds and the optional development server create `assets/data/mock-data.js` from this file. A missing dataset produces an empty, disabled fixture, so script references stay valid. Do not edit the generated file in `dist/`.

## Run fields

| Field | Meaning |
| --- | --- |
| `id` | Unique run ID; imported IDs use `mock-src-` |
| `runner` | Runner display name; the prototype uses this as runner identity |
| `category` | Board slug from `public/assets/js/domain/catalog.js` or `levels.js` |
| `timeMs` | Positive, safe integer RTA milliseconds |
| `date` | Run date as `YYYY-MM-DD`; empty string means unknown |
| `platform` | Hardware label; SNES and Emulator share a board, VC is separate |
| `region` | Region label or `Unknown` |
| `status` | `pending`, `verified`, or `rejected`; only verified runs rank |
| `video`, `comment` | Video URL and comment; empty strings are allowed |
| `reviewer`, `submittedAt`, `verifiedAt` | Moderation metadata; unavailable values may be empty |
| `sample` | `true` for imported fixture records |
| `source`, `sourceRunId`, `sourceUrl`, `sourceCategory`, `sourcePlatform`, `sourceValues` | Import provenance, preserved separately from board interpretation |

The importer resolves full-game Run Type and VC values from speedrun.com metadata when `--resolve` is supplied. It skips ambiguous or invalid records and never substitutes submission dates for missing run dates.

Imported records are never saved to browser storage. Local submissions use the existing `yoshi-visual-prototype-v1` key with `{ runs, viewer }`. That shape and key remain unchanged so existing browser data survives this reorganization.

`tests/fixtures/sample-data.js` is a separate fictional fixture for behavior tests.

## Individual Worlds

`individual-worlds.json` contains the public speedrun.com/yiext Individual Worlds snapshot, including source category and variable metadata. It covers World 1–6 and Extras with Warpless, 100%, and Warps. Refresh it with `npm run worlds:import`; the importer follows run pagination and refuses to replace the snapshot when any run cannot be mapped.

Builds package this snapshot alongside the optional mock dataset as `YOSHI_WORLD_DATA`. World runs load independently of the mock-data toggle and are never written to browser storage. They use `iw-<world>-<mode>` board slugs and real-time integer milliseconds. Only verified personal bests rank; previous verified records remain available in profiles and history. Source platform labels are retained (including Switch), with SNES and emulators on the combined board and local VC submissions on their separate board.
